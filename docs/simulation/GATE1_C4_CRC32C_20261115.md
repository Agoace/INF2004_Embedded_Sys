# C4 CRC32C table — operator decision, 2026-11-15

Operator approved this independent change on dd4c6d4. **TRIAL / NOT GATE1 PASS.**
Replace the eight bit-rounds per byte in `pil/wire.py` with a256-entry immutable
Castagnoli lookup table, prepared once at import before transport work. Polynomial
0x82f63b78, initial value0xffffffff and final XOR0xffffffff stay unchanged. This is
CRC32C, NOT IEEE CRC32. No protocol, validation, timing policy or hardware change.

Red-first tests compare the original bitwise function against table results for
random buffers, all frozen fixture contents and JSON hex fields. Valid, truncated
and every-single-bit-mutated golden wire vector retains the same decoded result
or error. The frozen158RX/58TX source fixture remains byte-identical.
